## Evaluation metrics (used for every model)

$$\text{MAE}=\frac1n\sum_{i=1}^{n}|y_i-\hat y_i| \qquad \text{MSE}=\frac1n\sum_{i=1}^{n}(y_i-\hat y_i)^2 \qquad \text{RMSE}=\sqrt{\text{MSE}}$$

$$R^2 = 1-\frac{SS_{res}}{SS_{tot}} = 1-\frac{\sum (y_i-\hat y_i)^2}{\sum (y_i-\bar y)^2}$$

For our two test rows: $SS_{tot} = (2.99-3.2550)^2 + (3.52-3.2550)^2 = 0.1404$.

> Note: with only two test rows, $R^2$ is very sensitive and may be negative. Negative $R^2$ simply means the model did worse than predicting the test mean. The full experiment (4,128 test rows) gives the reliable comparison.

## 1. Linear Regression

### Working procedure
1. Assume the target is a straight-line (linear) function of the input(s).
2. Choose the coefficients that minimise the sum of squared errors (Ordinary Least Squares).
3. For one feature, use the closed-form formulas for slope and intercept; for many features, use the Normal Equation.
4. Predict new points by plugging them into the fitted equation.

### Equations
$$\hat y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_p x_p \qquad J(\beta)=\sum_{i=1}^{n}(y_i-\hat y_i)^2$$

$$\text{Normal Equation: } \boldsymbol\beta = (X^TX)^{-1}X^T\mathbf y$$

$$\text{Simple LR: } \beta_1=\frac{\sum (x_i-\bar x)(y_i-\bar y)}{\sum (x_i-\bar x)^2},\qquad \beta_0=\bar y-\beta_1\bar x$$

## 2. Decision Tree Regression (CART)

### Working procedure
1. Start with all training rows in the root node.
2. For every feature and every candidate threshold (mid-point between two sorted values), split the rows into Left ($x_j \le t$) and Right ($x_j > t$).
3. Compute the Sum of Squared Errors (SSE) of each child around its own mean; choose the split with the **lowest total SSE** (= largest variance reduction).
4. Repeat recursively in each child until a stopping rule (max depth, min samples per leaf).
5. A leaf predicts the **mean** of the training targets that fall into it.

### Equations
$$SSE(S)=\sum_{i\in S}(y_i-\bar y_S)^2,\qquad \text{Cost}(j,t)=SSE(S_L)+SSE(S_R)$$

$$\text{Variance reduction}=SSE(S)-[SSE(S_L)+SSE(S_R)],\qquad \hat y_{leaf}=\frac{1}{|S_{leaf}|}\sum_{i\in leaf} y_i$$

## 3. Random Forest Regression

### Working procedure
1. Choose the number of trees $B$.
2. For each tree $b$: draw a **bootstrap sample** (n rows sampled *with replacement*).
3. Grow a decision tree on that sample, but at each split consider only a **random subset of features** (`max_features`).
4. To predict, pass the point through every tree and **average** the $B$ predictions.
5. Bootstrapping + random features make the trees different (decorrelated), so averaging reduces variance and over-fitting.

### Equations
$$\hat y_{RF}(x)=\frac{1}{B}\sum_{b=1}^{B} T_b(x),\qquad \operatorname{Var}(\bar T)=\rho\sigma^2+\frac{1-\rho}{B}\sigma^2$$

where $T_b$ is tree $b$, $\sigma^2$ the variance of one tree and $\rho$ the correlation between trees — lower $\rho$ (more random trees) and larger $B$ reduce the error.

## 4. Neural Network Regression (Multi-Layer Perceptron)

### Working procedure
1. **Scale the inputs** (z-score) — gradient descent works badly on features with different ranges.
2. **Forward pass:** each neuron computes a weighted sum plus bias, then a non-linear activation (ReLU). The output neuron is linear (regression).
3. **Loss:** compare prediction with the true value (squared error).
4. **Backward pass (back-propagation):** use the chain rule to get the gradient of the loss with respect to every weight.
5. **Update** every weight: $w \leftarrow w - \eta\,\partial L/\partial w$. Repeat for many epochs until the loss stops falling.

### Equations (network 1 input → 2 hidden ReLU neurons → 1 linear output)
$$z=\frac{x-\mu}{\sigma},\qquad a_k = w_k z + b_k,\qquad h_k=\text{ReLU}(a_k)=\max(0,a_k),\qquad \hat y = v_1h_1+v_2h_2+c$$

$$L=\tfrac12(\hat y-y)^2,\quad \delta=\frac{\partial L}{\partial \hat y}=\hat y-y,\quad \frac{\partial L}{\partial v_k}=\delta h_k,\quad \frac{\partial L}{\partial c}=\delta,$$

$$\frac{\partial L}{\partial w_k}=\delta\,v_k\,\mathbb 1[a_k>0]\,z,\qquad \frac{\partial L}{\partial b_k}=\delta\,v_k\,\mathbb 1[a_k>0]$$

### Step 1 – scale the input
$\mu = 3.4750$, $\sigma = \sqrt{\tfrac1n\sum(x_i-\mu)^2} = 2.2966$

## 5. XGBoost Regression (Extreme Gradient Boosting)

### Working procedure
1. Start with a constant prediction $\hat y^{(0)}$ (the mean of $y$).
2. Compute for every row the **gradient** $g_i$ and **hessian** $h_i$ of the loss with respect to the current prediction.
3. Build a new tree on $(g_i, h_i)$: try every split and keep the one with the largest **Gain** (which includes the L2 penalty $\lambda$ and split cost $\gamma$).
4. Each leaf gets an optimal weight $w = -G/(H+\lambda)$.
5. Add the tree to the model, shrunk by the learning rate $\eta$: $\hat y^{(t)} = \hat y^{(t-1)} + \eta f_t(x)$.
6. Repeat steps 2–5 for many rounds; each tree corrects the errors of the previous ones.

### Equations (squared-error loss)
$$\text{Obj}=\sum_i l(y_i,\hat y_i)+\sum_t\Big(\gamma T+\tfrac12\lambda\sum_j w_j^2\Big),\qquad l=\tfrac12(y_i-\hat y_i)^2 \Rightarrow g_i=\hat y_i-y_i,\; h_i=1$$

$$w_j^*=-\frac{G_j}{H_j+\lambda},\qquad \text{Gain}=\frac12\left[\frac{G_L^2}{H_L+\lambda}+\frac{G_R^2}{H_R+\lambda}-\frac{(G_L+G_R)^2}{H_L+H_R+\lambda}\right]-\gamma$$

where $G=\sum g_i$ and $H=\sum h_i$ over the rows in a node.

## 6. K-Nearest Neighbors Regression (KNN)

### Working procedure
1. Choose $k$ (number of neighbours) and a distance measure (Euclidean).
2. **Scale the features** — otherwise the feature with the largest range dominates the distance.
3. For a new point, compute its distance to every training point.
4. Select the $k$ closest training points.
5. Predict the **average** of their targets (or a distance-weighted average). There is no training phase — KNN is a *lazy learner*.

### Equations
$$z_{ij}=\frac{x_{ij}-\mu_j}{\sigma_j},\qquad d(\mathbf a,\mathbf b)=\sqrt{\sum_{j}(a_j-b_j)^2},\qquad \hat y=\frac1k\sum_{i\in N_k(x)}y_i$$

$$\text{distance-weighted: }\hat y=\frac{\sum_{i\in N_k} y_i/d_i}{\sum_{i\in N_k}1/d_i}$$

### Step-by-step solution ($k = 3$, features $x_1$ and $x_2$)
