Handwritten Math Derivations — 10 Lahore Houses (Zameen.com)

Sample: 8 Training houses (H1-H8), 2 Test houses (T1: 8 Marla/5 Bed, Actual: 1.52 Cr; T2: 14 Marla/4 Bed, Actual: 3.00 Cr).

1. Linear Regression (OLS): w1 = Cov(x, y) / Var(x) = 11.2388 / 53.7143 = 0.20923 Cr/Marla w0 = y_mean - w1 * x_mean = 1.7494 - 0.20923 * 8.375 = -0.0029 Cr T1 Prediction (8 Marla): y_hat = -0.0029 + 0.20923 * 8 = 1.671 Cr (Actual: 1.52 Cr, Error: +0.151 Cr) T2 Prediction (14 Marla): y_hat = -0.0029 + 0.20923 * 14 = 2.926 Cr (Actual: 3.00 Cr, Error: -0.074 Cr) MAE = 11.25 Lakh PKR | R² = 0.974 2. Decision Tree Regression: Best Root Split: x1 <= 8.5 Marla. Leaf 1 (Left: H1-H5) = 1.029 Cr | Leaf 2 (Right: H6-H8) = 2.950 Cr. T1 (8 Marla <= 8.5) -> y_hat = 1.029 Cr | T2 (14 Marla > 8.5) -> y_hat = 2.950 Cr. 3. Random Forest (B=2 Trees): Tree 1 & Tree 2 ensemble average: T1 Pred = (1.10 + 1.29) / 2 = 1.195 Cr | T2 Pred = (2.95 + 3.20) / 2 = 3.075 Cr. 4. Neural Network (MLP 1-Hidden Neuron): z = 0.5 * 8 - 1 = 3.0 -> a = ReLU(3.0) = 3.0 -> y_hat = 0.5 * 3.0 + 0.2 = 1.70 Cr. 5. XGBoost (Gradient Boosted Tree, gamma=0.1, lambda=1.0): Base y0 = 1.749 Cr. Leaf weight w_L = -0.60 Cr. y1 = y0 + eta * w_L = 1.749 + 0.3 * (-0.60) = 1.569 Cr (Very close to 1.52 Cr actual!). 6. KNN Regression (k=3 Euclidean Distance): Query T1 (8 Marla, 5 Bed): 3 nearest neighbors are H5 (1.50 Cr), H4 (1.18 Cr), H7 (2.45 Cr). y_hat = (1.50 + 1.18 + 2.45) / 3 = 1.710 Cr.

Cross-Market Engineering Architecture

  • Leak-Free Preprocessing Pipelines: In both markets, all scaling, one-hot encoding, and target-encoding pipelines were fit strictly on the 80% training split. Zero test data was leaked into feature scalers.
  • Target Skew Management: In the Pakistani real estate market, prices span multiple orders of magnitude (from 35 Lakh flats to 25 Crore DHA mansions). The models trained on log(price) and converted back with exp(.), resulting in a dramatic jump in performance (XGBoost R² 0.9178 vs Linear Regression 0.8413).
  • Why XGBoost Won Across Both Continents: XGBoost captured complex non-linear spatial interactions (GPS coordinates and proximity premiums) and categorical neighborhood boundaries without overfitting due to its second-order Hessian tree splitting and L1/L2 regularization.
